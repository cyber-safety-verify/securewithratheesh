# SecureWithRatheesh — Permanent QR Profile

This is the static GitHub Pages version. No Node.js server and no localhost are required.

## Upload
Upload `index.html`, `style.css`, `generate-qr.html`, and the `assets` folder to a GitHub repository.

Put your photo at:
`assets/profile.jpg`

## GitHub Pages
Enable GitHub Pages for the repository using the `main` branch and root folder. Your public URL will look like:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## QR
Open `generate-qr.html`, enter the final public HTTPS URL, generate the QR, and download it.

The QR does not expire by itself. It continues working as long as that public URL remains available.

## YouTube
The button uses:
`https://www.youtube.com/@securewithratheesh?sub_confirmation=1`

This may show YouTube's subscription confirmation UI where supported. It cannot force a subscription; the visitor must confirm it.

## Important
Do not use localhost in the final QR.
